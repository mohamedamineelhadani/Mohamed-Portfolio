# Mohamed Amine El Hadani | Portfolio

A responsive full stack developer portfolio with a classic luxury look (dark and orange, with a light theme), a contact form that saves messages to a database, and a private admin page to read them.

## Features

- Responsive design (desktop, tablet, mobile) with a mobile menu
- Dark / light theme switch (the "M" button)
- Inline SVG icons (no icon library needed)
- Contact form saved to MySQL
- Admin login to view received messages

## Tech stack

HTML, CSS, JavaScript, PHP, MySQL
